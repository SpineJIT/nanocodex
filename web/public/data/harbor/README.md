# Generated Harbor data

These files are generated by `web/scripts/sync-harbor.mjs`. Do not edit the
JSON by hand.

- `index.json` contains the retained job and trial index plus the latest
  validated A/B comparison.
- `summary.json` is the small public projection used outside the full eval
  browser.
- `trials/` contains the retained per-trial detail records linked from the
  website.
- `web/src/data/harbor-summary.json` is the build-time copy of `summary.json`
  used by the homepage.

`comparison: null` means that no retained pair passed the immutable experiment
plan checks. It does not mean that the retained jobs or trials were removed.
